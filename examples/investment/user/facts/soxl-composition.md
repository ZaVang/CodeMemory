# SOXL 构成与特性

SOXL（Direxion Daily Semiconductor Bull 3X Shares）是 3 倍杠杆 ETF，追踪 ICE Semiconductor Index。

## 核心持仓（截至 2026-02）

| 成分 | 权重 | 说明 |
|------|------|------|
| NVIDIA (NVDA) | ~12% | AI 芯片龙头 |
| Broadcom (AVGO) | ~10% | 网络芯片 + AI ASIC |
| AMD | ~8% | CPU + GPU |
| ASML | ~7% | 光刻机 |
| Applied Materials | ~6% | 半导体设备 |

## 特性

- 3 倍杠杆：标的指数涨 1% → SOXL 约涨 3%；跌 1% → 约跌 3%
- NVIDIA 占标的指数 ~12%，加上杠杆效应，NVIDIA 跌 5% → SOXL 约跌 1.8%（1.8% ≈ 12% × 5% × 3）
- 高波动：日振幅常在 5-10%
- 不适合长期持有（杠杆损耗）
