# 不喜欢拥挤的地方

## 感受

每次被迫去人多的商场就会心情不好。不是社恐——和人一对一交流完全没问题——而是嘈杂的、拥挤的、到处排队的消费场所让人窒息。

## 替代方案

周末更愿意去：
- 郊区的公园（人少、安静、有树）
- 在家看书或者看电影
- 去小众的咖啡店坐一下午
