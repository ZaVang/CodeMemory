# CodeMemory 洞察与奇思妙想

> **Idea log, not canonical spec**  
> 本文保留项目最初的哲学洞察与灵感来源，不再直接定义 v1 产品边界。  
> 当前正式产品定义见 `docs/prd.md`，正式架构见 `docs/architecture.md`。

> 记录项目设计过程中产生的哲学隐喻、跨领域联想与核心洞察。
> 这些想法不直接定义实现，但决定了系统的设计方向。

---

## 1. 代码即因果模型

**洞察**：代码间的 `import` 是有方向的因果箭头——“理解 B 之前必须先读 A”。这天然构成了有向无环图（DAG），与因果推断中的因果图同构。

**启发**：
- 记忆加载是依赖解析问题，不是搜索问题。
- 禁止循环引用，因为它意味着没有因果起点。
- LLM 在代码上的特化训练，使其天然适应这种结构。

---

## 2. 透明玻璃与雨水

**场景**：下雨时，我可以在“看玻璃上的水珠”和“穿透玻璃看窗外”之间自由切换。正常晴天，玻璃完全透明，我甚至意识不到它的存在。

**映射**：
- **窗外风景** = 记忆库中的所有知识
- **透明玻璃** = Agent 与记忆系统之间的理想接口
- **雨水** = 对话中的噪音、token 压力，它让接口变得可见
- **聚焦切换** = `--depth full` vs `--depth summary` 的动态调整

**启示**：最好的记忆接口是透明的——Agent 在使用时感觉不到它的存在。只有当“下雨”（冲突、过期、预算紧张）时，系统才显式提醒 Agent 该调焦了。**Layer 0 应是这层透明玻璃。**

---

## 3. 触景生情与不可达

**洞察**：遗忘不是删除，是路径不可达。某段记忆一直存在，但缺少触发条件。一旦场景匹配（气味、地点、情绪），记忆瞬间涌现。

**映射**：
- 不被任何 composite 引用的 atom = 不可达的记忆
- 对话中的关键词/tags = 触发条件
- 联想搜索与随机漫步 = 人工制造“触景”

**启示**：遗忘应自然发生，由依赖图结构决定。系统不需要主动删除，只需提供“重新发现”的机制（如随机漫步、联想匹配）。

---

## 4. 单词与车祸：记忆强度

**洞察**：每天背的单词容易忘（浅层刻痕），而一次车祸终生不忘（深深刻印）。区别不在路径，而在记忆本身的强度。

**映射**：
- `intensity` 字段标记记忆的不可衰减程度
- 高 access_count / 高被依赖度 → 自然重要，无需显式打分
- 冷记忆可被骨架化或建议压缩，但永不自动删除

**启示**：重要性不应由系统评估，而应从拓扑位置和访问频率中涌现。系统只提供衰减建议，由人决策。

---

## 5. 视觉残留与重构

**场景**：隔板记忆游戏中，我不记具体坐标，而是靠视觉残留的拓扑印象，在球发射瞬间当场推导路径。

**启示**：
- 记忆不必存储所有细节，只存储“模式 + 关键帧”，在 recall 时重建。
- 可以引入**瞬态记忆**：当前会话的推理 DAG，不落盘，但可被解析。通过 `snapshot` 命令导出为 composite 持久化。
- 系统本质上是一个**重构引擎**，而非存储数据库。

---

## 6. 双焦距与分辨率层级

**场景**：人眼可以在“聚焦近处细节”和“模糊但大视野看远景”之间即时切换。

**映射**：
- `resolve --depth full` = 聚焦某个记忆的完整正文
- `resolve --depth required` = 只加载 summary，获得拓扑全貌
- `focus` 工具 = 允许 Agent 对已加载的上下文动态缩放，不重新 resolve

**启示**：Agent 默认应以“远景模式”运行，只在需要时放大特定节点。

---

## 7. 通用原则：让环境适应 LLM，而非相反

**洞察**：LLM 对 POSIX 指令、代码结构、文件树有神经适应性。Claude Code 只用 file edit + bash，Virtual FS 用 cat/grep/find/ls 暴露 rag，都因 LLM“天生会用勺子”。

**启示**：
- 把记忆塑造成代码文件和 import DAG，而非设计新数据库。
- 工具链使用最简单的文件操作和 CLI，最大限度利用 LLM 已有能力。
- 整个 memory 系统应是 LLM 已经知道如何管理的东西。

---

## 8. 自组织记忆生态

**最终愿景**：记忆系统不依赖中心化的重要性评估或删除策略。记忆们自行构成一个有生有灭的生态：
- 被频繁引用的 → 热度升高，被保护
- 不被引用的 → 逐渐不可达，自然遗忘
- 高强度标记的 → 永远存活，如创伤记忆
- 联想漫步 → 偶然激活沉睡记忆，完成“触景生情”

系统扮演的角色是维护这个生态的规则，而不是决定每条记忆的命运。
